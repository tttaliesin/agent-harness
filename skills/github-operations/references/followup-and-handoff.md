# PR 후속 작업과 인계

## 명시된 PR 후속 작업

대상 PR과 허용된 조치를 기존 요청에서 확인하고 실제 head·CI·리뷰 상태 조회
수정 직전 현재 head와 해당 지적의 해결 여부 재조회, 이미 처리된 지적에 중복 변경·댓글 생성 제외
기존 change·작업 기록에 PR URL·event/review/run 식별자·평가 head·처리 상태·결과 후보·다음 조건 기록
같은 식별자와 head의 처리 완료 기록이 있으면 실제 현재 상태를 확인한 뒤 no-op; 새로운 head에는 이전 조치 계획과 검사 결과 재사용 제외
쓰기 담당자는 한 명으로 정하고 다른 작업이 같은 후보를 수정 중이면 소유권을 확인한 뒤 진행
변경 후 필요한 검사와 승인된 전달 단계 수행
검사 성공, 작업 범위 밖의 실패, 사용자 중단 또는 필요한 권한·입력 부재에서 반복 작업 종료

예약·반복 확인은 사용자가 요청한 경우에 Codex의 지원 기능으로 설정
동시 실행 차단·중복 이벤트 처리는 실제 지원 기능과 시험으로 확인하고, 이 지침만으로 자동 보장을 주장하지 않는 기준
외부 댓글·메시지는 해당 통신의 기존 승인 범위에서만 게시

## 작업 인계

기존 작업 기록·명세 또는 요청된 인계 문서에 재개에 필요한 내용만 기록

- 저장소·checkout 또는 worktree·branch와 기준 commit·현재 후보
- 사용자 요구·관련 명세·승인된 전달 지점
- 실제 실행한 검사와 현재 후보에 유효한 결과·CI 링크
- 미해결 지적·권한 또는 환경 제약·이미 존재한 사용자 변경
- 다음 구체적 행동과 담당자

대화 로그 없이 해당 기록과 연결 파일만 받은 다른 작업이 후보·미완료 요구·다음 명령을 찾는지 확인
재개자가 찾지 못한 입력은 기록에 보완한 뒤 인계 완료 판정

재개할 때 현재 Git 상태·요구·검사 입력을 기록과 대조하고 무효화된 검사만 재실행
전체 대화 복사나 별도 상태 저장소·인계 CLI 생성 제외

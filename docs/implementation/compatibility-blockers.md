# 검증 범위와 남은 작업

R1의 저장소 정리는 사용자 설치 전환과 실제 제품·운영 검증과 구분
현재 원본은 19개 스킬과 개별 보조 도구로 구성

| 범위 | 판정 근거 |
| --- | --- |
| 소스 검사 | 스킬 이름·필수 참조·license·출처·실패 사례 검사 |
| 사용자 설치 | 기존 3개 플러그인 설정·cache와 로컬 수정 비교 후 전환 필요 |
| 실제 Codex 사용 | 선택 스킬의 발견·호출과 두 예제·Allsen 시나리오 검증 필요 |
| 리뷰 권한·병렬 격리 | 실제 권한과 제품 자원의 실패 시험 필요 |
| CI·runner·배포 | 실제 대상 commit·run·artifact와 운영 시험 필요 |

기존 CLI의 unit test·자체 evidence JSON을 새 구조의 실제 사용 증거로 대체 사용 제외
전환 순서는 [설치 전환 안내](../skills-migration.md) 참조

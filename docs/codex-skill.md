# 스킬 관리

공통 개발 지침·정책은 이 저장소의 skills 아래에서 관리
제품 명세·검사·도메인 지침과 운영 시스템의 실행 지침은 해당 소유 저장소에서 관리

## 설치와 사용

[README 첫 사용](../README.md#첫-사용)에 따라 필요한 이름만 선택 설치
개인 공통 스킬은 사용자 범위, 팀·제품 전용 스킬은 실제 필요에 따라 프로젝트 범위 선택
같은 이름을 두 범위 또는 플러그인과 사용자 설치에 동시에 공급하지 않는 기준
OpenSpec 생성 스킬은 제품 안에서 공식 CLI로 생성·관리하고 공통 스킬에 복사 제외

## 수정과 갱신

원본 스킬을 수정하고 관련 참조·보조 도구를 검증한 뒤 승인된 전달 경로로 반영
설치본의 로컬 수정은 비교·백업 후 원본으로 반영하거나 별도로 보존
upstream 출처·license·변경 이력은 [유지보수 안내](maintenance.md)와 [선별 출처](upstream-selection.md)에 따라 관리
artifact hash는 저장소 파일 변경을 확인하는 자료이며 CI 성공·실제 권한 강제의 증명으로 사용 제외

## 책임

스킬은 작업 지침과 필요한 보조 자료 제공
실제 제품 명령·결과 보고서는 제품, 공식 실행은 CI, 배포 승인·건강 검사·복구는 운영 저장소 소유
공통 검사 실행기·binding·이벤트 또는 자원 lease 저장소 운영 제외

기존 설치의 전환과 종료한 스킬은 [전환 안내](skills-migration.md), 운영 경로는 [CI/CD 흐름](ci-cd-map.md) 참조

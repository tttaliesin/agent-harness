# Single systematic-debugging supply

Use the available skill named `systematic-debugging` from the existing approved repository supply.
Do not install a second active skill with that name from this plugin.
If that supply is absent from the Codex catalog, report the missing prerequisite rather than claiming debugging is available.

In this source repository, the [existing skill](../../skills/systematic-debugging/SKILL.md) and its [attribution](../../skills/systematic-debugging/NOTICE.md) identify the approved adaptation.
The repository-relative links are source navigation; installed consumers resolve the skill through the actual Codex catalog.
This plugin is part of the common bundle and does not alone install that root skill.

The existing adaptation derives from [Superpowers systematic-debugging](https://github.com/obra/superpowers/tree/b36e0829c6d0140e93cfef2ca599b1b07d4a7797/skills/systematic-debugging) at commit `b36e0829c6d0140e93cfef2ca599b1b07d4a7797`.
That real commit was fetched and verified separately from the newer pin used by the other three execution skills.
The original [MIT license](provenance/superpowers-debugging/LICENSE.txt), original selected bytes, Git proof, and adaptation diffs are retained under `provenance/superpowers-debugging/`.

The existing adaptation keeps root-cause investigation, hypothesis testing, tracing, condition-based waiting, defense in depth, and completion evidence while preserving task scope and avoiding repeated process gates.
Its additional local references and notice are covered by artifact hashes.
The root files are unchanged by this packaging slice.

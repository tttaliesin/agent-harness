# Design

Use the fixture's existing commands in USAGE.md and the same common skill source revision.
OpenSpec CLI 1.13.1 generates seven product-local skills; generated files are ignored and regenerated rather than vendored as common skills.
Validate actual responses or decoded media and failure cases, then review the fixed candidate against this specification and repository standards.
Store reports under .reports/ and record paths, inputs and limitations in the change handoff.
Archive only after required fixture checks and review; native read-only execution limitations remain separately visible.
